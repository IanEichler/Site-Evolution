# Mentoria Evolution

Landing page responsiva da Mentoria Evolution com Luciane Magalhães.

## Publicação na Vercel

O projeto é um site estático e não exige instalação de dependências ou comando de build. O arquivo `vercel.json` configura a pasta `dist` como saída pública.

Para publicar, importe este repositório na Vercel. As configurações versionadas serão aplicadas automaticamente.

## Estrutura

- `dist/index.html`: conteúdo da página.
- `dist/modern.css`: estilos responsivos.
- `dist/app.js`: menu, galeria, vídeos e chamada móvel.
- `dist/motion.js`: animações de entrada com suporte a movimento reduzido.
- `dist/assets/`: fotografias e miniaturas dos depoimentos.
